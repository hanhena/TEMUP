# RE:PIN 인장 커스터마이저 (Tampermonkey)

리핀 웹 대화를 사용자 브라우저에서 꾸미는 비공식 유저스크립트입니다.

## 설치

Tampermonkey가 설치된 브라우저에서 아래 링크를 열어 **설치**를 선택합니다.

**[템퍼몽키 설치 링크](https://raw.githubusercontent.com/hanhena/TEMUP/main/repin-avatar.user.js)**

스크립트가 이미 설치되어 있다면 **기존 스크립트를 먼저 비활성화하거나 삭제하여 중복 실행을 방지**하세요. PC용 RE:PIN 확장프로그램과도 동시에 켜지 않는 것을 권장합니다.

## 기능

- 대본-개편 테마 및 사각형 캐릭터 인장
- 작품별 인장 변경·이미지 자르기
- 같은 이름의 캐릭터를 여러 작품에서 사용하는 공용 인장 보관함
- 채팅 하단의 인장 메뉴
- PC 확장프로그램의 인장 설정 JSON 가져오기 및 백업 다운로드
- 새 방 자동 적용과 테마 중복 처리 개선

## 업데이트

이 저장소의 `repin-avatar.user.js`를 수정할 때 헤더의 `@version`도 올리면 Tampermonkey가 GitHub Raw 주소에서 업데이트를 확인할 수 있습니다.

현재 버전: **1.8.3** (1.8.2와 기능 동일, GitHub 자동 업데이트 주소 수정).

## 주의

- 리핀 **공식 앱**이 아니라 사용자 스크립트를 실행할 수 있는 **모바일 웹 브라우저**에서 이용합니다.
- 인장과 대화별 설정은 브라우저별 로컬 저장입니다. PC와 모바일 간 이동 시 JSON 백업/가져오기를 사용해야 합니다.
- 백업 JSON에는 개인 인장 이미지가 포함될 수 있습니다. **GitHub 공개 저장소에 백업 JSON을 업로드하지 마세요.**
- 리핀 사이트 화면 구조가 변경되면 일부 기능이 작동하지 않을 수 있습니다.

이 프로젝트는 리핀 공식 기능이 아닙니다.
